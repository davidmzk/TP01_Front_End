# Práctica Formativa Obligatoria 1  
## Landing Page de Portafolio Personal (HTML y CSS)

Este proyecto corresponde a la **Práctica Formativa Obligatoria 1**.  
Consiste en el desarrollo de una Landing Page de Portafolio Personal utilizando únicamente **HTML y CSS**, aplicando estructura semántica, diseño responsivo, uso de Google Fonts, Flexbox y estilos personalizados.

El objetivo fue crear un sitio web estructurado correctamente, visualmente atractivo y adaptable a distintos dispositivos.

### Layout y Organización:

[x] Se ha organizado el layout (especialmente en la sección "tarjetas") utilizando Flexbox.  

**¿Qué ventajas encontré al utilizar Flexbox?**  
Flexbox facilita la distribución y alineación de elementos en filas o columnas.  
Permite que el diseño sea flexible y adaptable, especialmente cuando se trabaja con tarjetas o componentes que deben ajustarse automáticamente en distintos tamaños de pantalla.
